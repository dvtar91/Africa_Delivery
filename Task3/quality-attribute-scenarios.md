# Сценарии атрибутов качества — Africa Delivery

**Status:** test design, not production test report. Six fields per scenario: source, stimulus, environment, artifact, response, measure. Baseline: Task2 modular monolith; two-country pilot **subject to юридического согласования**. Targets are provisional pending capacity measurement.

| ID / характеристика | Источник воздействия | Воздействие | Условия | Объект | Ожидаемая реакция | Измеримый результат / приёмка |
|---|---|---|---|---|---|---|
| QAS-01 availability catalog | Buyer / synthetic probe | App container dies mid-request | 100 catalog RPS, single replica failure, normal service | LB, app, CDN/catalog | Healthy replica answers, stale public catalog allowed | ≥99.9% 30d good response SLI, failover symptom ≤60s in drill; no stale prices at оформлении заказа |
| QAS-02 availability PSP | PSP / external network | PSP timeout, 5xx, delayed webhook | 10 оформлении заказа RPS, partner outage 15 min | Order/Payment adapter, журнал исходящих событий | Circuit opens, persist pending, webhook reconciles; no fake paid | 0 число повторных финансовых операций after 100k replay; timeout ≤3s for internal intent; unsettled alerts after 15min |
| QAS-03 задержка P99 | Контрольный пользователь 3G | Удвоенный пик запросов и ограниченная сеть 3G | Нагрузочный тест k6 и бюджетный Android | API каталога и CDN | Кеширование, уменьшение изображений, ограничение нагрузки | p99 API ≤1 с при базовых 100 запросах/с; p75 первого товара ≤2 с — экспериментальная цель |
| QAS-04 throughput | Campaign traffic | Surge in catalog reads / orders | 100 catalog +10 оформлении заказа sustained RPS, 30min and 2× 5min | LB, pool, DB, queue | Scale stateless app, load shedding safely | ≥99% successful catalog responses baseline; order intent ≥99.9%, DB pool no exhaustion; peak RPS annotated |
| QAS-05 восстановление RTO/RPO | Сбой узла или хранилища | Остановка основной БД / повреждение испытательной реплики | Учебное восстановление из резервной копии и журнала транзакций в разрешённой стране | БД, копии, заказы | Изоляция отказа, восстановление и сверка PSP | RTO ≤60 мин, RPO БД ≤15 мин; несверенные финансовые события блокируют возобновление |
| QAS-06 PII isolation | Malicious/misconfigured export | NG PII sent to unapproved KE/EU sink | Pen-test + migration dry run | Egress, logs, analytics, backup | Deny and log, flag Безопасность+Legal | 0 unauthorised cross-border transfers; block test fixtures for each country |
| QAS-07 mobile reliability | Unstable mobile network | Client times out after оформлении заказа submit, retries | 3G loss/reorder 5%, PSP callback delayed | API order idempotency | Same order ID returned, no duplicate charge | 100k retry/replay tests, 0 duplicate confirmed payment effects |
| QAS-08 notifications degradation | SMS/WA vendor | Vendor 429/503 for 30min | Live queue simulator | Outbox + provider adapters | Bulkhead + exponential retry, do not affect оформлении заказа | Checkout intent SLI unaffected; alert queue lag >10min, messages never to unconsented recipients |
| QAS-09 переносимость | Эксплуатация / миграция | Смена согласованного провайдера или региона | Испытательная среда, подписанные образы OCI | Инфраструктура как код, приложение, миграции БД | Воссоздание среды и восстановление в законных границах | Развёртывание с нуля ≤30 мин, без обязательной зависимости от Kubernetes |
| QAS-10 наблюдаемость | Дежурный инженер | Искусственные 5xx, задержки и насыщение | Испытательная среда с нагрузкой | Система телеметрии | Оповещение с инструкцией и связанной трассой | Оповещение ≤5 мин, четыре золотых сигнала, отсутствие персональных данных в журналах |

**Проверка:** k6, эмуляция мобильной сети в Playwright и проверка на реальном устройстве, имитация PSP и вебхуков, сетевые сбои через Toxiproxy, восстановление резервной копии. Сценарии и предложенные SLO не означают успешной приёмки; результаты и ответственные фиксируются после испытаний.
