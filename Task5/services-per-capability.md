# Сервисы, реализующие возможности платформы

**Примечание:** слово «сервис» означает логический модуль или внешний договорный продукт; **не** микросервис. Используется монолит ADR-001 с отдельными развёртываниями по стране ADR-003.

| Возможность | Продукт/сервис (реализация) | Владелец | Внешняя зависимость | Способ |
|---|---|---|---|---|
| C01 Ассортимент | Модуль каталога PostgreSQL, хранилище публичных изображений/CDN | Технический руководитель каталога + Product | Локальное хранение при PII, CDN provider | Разработка + покупка технической услуги |
| C02 Поиск | PostgreSQL full-text + нормализация, без ML | Разработчик каталога | Наличие расширений в разрешённом регионе | Разработка |
| C03 Оформление | Модуль корзины, заказа, резервирования остатков, идемпотентности | Руководитель backend | PostgreSQL, локальный ЦОД | Разработка |
| C04 Продавцы | Модуль аккаунта продавца/KYB, ручная модерация | Product/Operations | Проверочный поставщик после legal review | Разработка + партнёрство |
| C05 Расчёты продавцов | Журнал намерений и внешних идентификаторов, reconciliation worker | CFO + Payments lead | PSP и банк, расчётный календарь | Разработка + партнёрство |
| C06 Платежи | Модуль Payment Adapter, подписанные вебхуки, PSP-hosted checkout | Payments lead | M-Pesa/Flutterwave/Paystack в конкретной стране после договора | Партнёрство + адаптер |
| C07 Возвраты | Панель оператора, рабочий процесс возврата, PSP refund API | Operations + Legal | PSP, правила потребительских возвратов | Разработка + партнёрство |
| C08 Доставка | Fulfillment Adapter и статусы / обработка исключений | Operations + CTO | Sendbox, Sendy: география, договор и SLA не подтверждены | Партнёрство + адаптер |
| C09 Маршрутизация/курьеры | Сервис оптимизации маршрута, потенциальное выделение домена | CTO/Operations | Курьеры, GIS, страхование и нормы | Отложить, затем оценить разработку |
| C10 Уведомления | Outbox Worker, Consent Ledger, SMS/WhatsApp adapter | Product + Security | Оператор/шлюз, согласия и местные законы | Разработка + покупка услуги |
| C11 Операционный контроль | Backoffice, управляемые отчёты, агрегированный KPI | CEO/Product | Законное агрегирование между странами | Разработка |
| C12 Платформа | OCI приложение, страны NG/KE, PostgreSQL, backup/PITR, OpenTelemetry | CTO/DevOps/Security | Локальные поставщики и юридические договоры | Разработка + покупка услуги |
| C13 Новые каналы | Языковая локализация, USSD Gateway Adapter, PWA | Product | Операторы, переводчики, app stores | Позже; партнёрство + разработка |
| C14 Новые бизнес-модели | Live streaming, ML recommendation, loyalty, B2B | CEO/Product | Видео/скоринг/финрегулирование | Позже; отдельный бизнес-кейс |

**Контракт модулей:** идентификатор страны во всех операциях, порты адаптеров PSP/логистики, разделение PII и доменной логики, outbox с повторной доставкой, schema migration, нагрузочные границы из [Task3](../Task3/nfr-registry.md). Внешние интерфейсы не объявлять доступными до договора, а передачу PII — разрешённой до [Task4](../Task4/data-residency-map.md).
