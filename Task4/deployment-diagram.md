# Deployment Diagram — размещение и границы переключения

**Формат:** Mermaid `flowchart` с развёртыванием по странам и физически независимыми площадками только как **целевыми**, не приобретёнными. Для NG/KE локальные поставщики и второй ЦОД **не подтверждены**. Монолит — один код в двух раздельных страновых развертываниях. Стрелки миграции данных через границу страны отсутствуют намеренно.

```mermaid
flowchart TB
    U["Клиент / продавец"] --> R["Маршрутизатор по стране без хранения PII"]
    subgraph NG["Нигерия — допустимый местный контур, поставщик не выбран"]
       subgraph NGA["Площадка NG-А — первичная"]
          NA["NG приложение, 2 экземпляра"] --> NDB[("PostgreSQL NG: основной узел")]
          NW["NG обработчик outbox"] --> NDB
       end
       subgraph NGB["Площадка NG-Б — резерв, при наличии договора"]
          NR["NG резервное приложение"] --> NDR[("Реплика NG, только если разрешена и доступна")]
          NB[("NG зашифрованные копии / ключи")]
       end
       NDB -. "Внутристрановая репликация; только после проверки" .-> NDR
       NDB -->|"PITR/резервное копирование внутри NG"| NB
    end
    subgraph KE["Кения — допустимый местный контур, поставщик не выбран"]
       subgraph KEA["Площадка KE-А — первичная"]
          KA["KE приложение, 2 экземпляра"] --> KDB[("PostgreSQL KE: основной узел")]
          KW["KE обработчик outbox"] --> KDB
       end
       subgraph KEB["Площадка KE-Б — резерв, при наличии договора"]
          KR["KE резервное приложение"] --> KDR[("Реплика KE при согласованном SLA")]
          KB[("KE зашифрованные копии / ключи")]
       end
       KDB -. "Внутристрановая репликация; только после проверки" .-> KDR
       KDB -->|"PITR/резервное копирование внутри KE"| KB
    end
    subgraph ZA["ЮАР — будущий, неактивный контур"]
       ZAAPP["Кандидат: AWS Кейптаун или GCP/Azure Йоханнесбург"]
    end
    R -->|"Только запросы NG"| NA
    R -->|"Только запросы KE"| KA
    P["Лицензированные PSP и логистика после согласования"]
    NA -. "Минимальные договорные данные" .-> P
    KA -. "Минимальные договорные данные" .-> P
    NOC["Дежурный и локальные метрики; без сырых PII вне страны"]
    NA -->|"Обезличенные сигналы"| NOC
    KA -->|"Обезличенные сигналы"| NOC
```

**Режим отказа:** NG-А → NG-Б или KE-А → KE-Б **только после** подтверждения второго местного ЦОД, непрерывной репликации, fencing прежнего primary и проверки расхождений PSP. **Не переключать** NG в KE/ЮАР и KE в NG/ЮАР по умолчанию. При отсутствии второго местного ЦОД — остановка создания заказов и безопасное восстановление на разрешённой площадке. См. [failover-plan.md](failover-plan.md).
